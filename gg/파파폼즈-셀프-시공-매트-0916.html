📍 구매 방법 안내

➊ 시공할 공간을 선택
거실 / 거실+복도 / 거실+복도+아일랜드 /
거실+복도+아일랜드+주방 / 아기방 / 안방

➋ 셀프시공 vs 전문가 시공을 선택
👉🏻 거실 / 이가방 / 안방 단독 → 셀프시공 추천
👉🏻 복도 포함시 → 전문가 시공 추천
▸ 셀프시공 : 공간 가로×세로 실측 후 필요한 수량 확인
( 피드 or 구매링크 내 실측 방법 확인 가능 )
▸ 전문가시공 : 공간 실측 없이 견적 설문폼으로 신청

➌ 매트 옵션 선택
▸ 컴팩트 700x700 : 프렌치바닐라
▸ 클래식 800x800 : 데이라이트, 문라이트스톤, 프렌치바닐라, 솔리드그레이
▸ 플러스 1200x800 : 데이라이트, 문라이트스톤, 프렌치바닐라, 솔리드그레이
▸ 맥스 1200x1200 : 문라이트스톤

✔️ 셀프시공(800x800)은 커넥터 / 노커넥터 중 선택 가능
👉🏻 커넥터형 : 재단 없이 필요한 공간에 간편하게 설치
👉🏻 노커넥터형 : 벽면까지 빈틈없이 압착 시공해 더 깔끔하게

➍ 구매/견적 신청 완료
▸ 셀프시공 : 바로 결제 & 익일 출고(주말, 공휴일 제외)
▸ 전문가시공 : 설문폼 제출 → 해피콜 → 시공일예약(1~2주후로 가능) → 계약금 없이 시공 후 후불 결제

📍 매트 컬러 안내

▸ (해달픽) 문라이트 스톤
은은한 스톤 그레이 컬러로 고급스러운 느낌
▸ 데이라이트
베이지톤 배경 위에 마블 패턴이 더해져 따스한 느낌
▸ 프렌치바닐라
가장 웜톤의 컬러! 옐로우 크림빛의 포근한 느낌
▸ 솔리드 그레이
화이트 베이스에 그레이 결이 더해진 대리석 감성

📍 매트 사이즈 추천

✅ 셀프시공으로 거실 또는 방만 단독으로 하신다면
기본 클래식 800x800 사이즈 추천!

✅ 전문가 시공으로 하신다면
