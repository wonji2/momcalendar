📌 프로살림 자동 연필깎이

▪️ 5단계 심 조절 가능
▪️ 둥근·삼각·육각 연필 + 색연필 모두 사용 가능
▪️ 꺼내보지 않아도 바로 확인되는 대용량 연필가루통
▪️ 과열 보호 회로 적용
▪️ C-TYPE 충전 방식 (완충 시 약 1,000회 사용)
▪️ 어린이제품안전특별법에 의한 안전확인 인증

🔎 오토베어 vs 오토베어 점보 차이!

✔️ 오토베어
→ 일반 연필, 일반 색연필 사용 시 추천
→ 상대적으로 균일하고 세밀하게 깎임

✔️ 오토베어 점보
→ 굵은 점보 사이즈 연필까지 사용 가능
→ 리라그루브 점보 사용하신다면 요걸로 추천🙌🏻

※ 현재 함께 공구 중인 리라그루브 ‘트리플원’ 사이즈는
호환되는 자동 연필깎이가 없어요!
