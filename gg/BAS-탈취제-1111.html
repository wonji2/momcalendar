국민탈취제라 불리는 BAS!
✅ BAS의 특장점 정리해봤어요
- 후기들이 입증하는 강력한 탈취력
- 새집 증후군, 헌집 냄새, 반려동물 냄새 등 싹~
- 최대 3개월 끝까지 유지되는 탈취지속력
- 향으로 덮지 않고 냄새 분자를 제거하는 기술력
- 화장품 구성 성분으로 순하니 안심(유해물질 Zero)
- 고체형으로 안전하게 사용 가능
- 다양한 향으로 취향에 맞게 사용 가능
- 선물추천 판매 1위 탈취제

💕구성 안내
✔️ 퓨어화이트 펫 450g
반려동물과 함께하는 공간을 위한 전용

✔️ 블랙라벨 고체탈취제 350g
플레인 무향 / 섬머린넨 / 베이비파우더
향에 민감하시다면 플레인(무향)을 추천드려요✨

✔️ 겔 타입 탈취제
강력한 탈취가 필요한 곳엔 겔 타입을 추천해요
블루·오렌지·에메랄드 397g / 핑크 350g

✔️ 미니플러스 160g
좁은 공간에 맞게 작은 사이즈도 있어요
플레인 무향 / 베이비파우더 / 플로랄부케

✔️ 냉장고 전용 탈취제
냉장고 속 음식 냄새까지 따로 관리!

이사, 개업, 집들이 등등 좋은 일에 선물하기 너무 좋아요!
