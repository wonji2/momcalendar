## 1. 사장님이 하실 것 — 계정

1. **D-U-N-S 번호** 확인/신청 (사업자): https://developer.apple.com/enroll/duns-lookup/  (무료 · 1~2주)
2. **Apple Developer Program** 가입 (조직 · 연 $99): https://developer.apple.com/programs/enroll/
3. 가입되면 **팀 ID(10자)** 를 알려주세요 → `APPLE_TEAM_ID` (developer.apple.com → Membership details)

## 2. 사장님이 하실 것 — 인증서·키 (가입 후 · 각 1회)

developer.apple.com → Certificates, Identifiers & Profiles

| 만들 것 | 어디서 | 비고 |
|---|---|---|
| **App ID** `com.wontsbe.momcalendar` | Identifiers → + → App IDs | Capabilities 에서 **Push Notifications 체크** (안 켜면 CI 가 프로파일 검사에서 멈춘다) |
| **Apple Distribution 인증서** | Certificates → + | 윈도우라 CSR 을 못 만든다 → 내가 CSR 파일을 만들어 드리면 올려서 .cer 받기 → 내가 .p12 로 묶는다(비밀번호 설정) |
| **APNs 키 (.p8)** | Keys → + → Apple Push Notifications service (APNs) | Key ID 10자 · 파일은 **한 번만** 받을 수 있다 (잃어버리면 새로 발급) |
| **프로비저닝 프로파일** (App Store) | Profiles → + → App Store Connect | 위 App ID + 위 인증서 선택 |
| **App Store Connect API 키** | appstoreconnect.apple.com → Users and Access → Integrations → App Store Connect API | 역할 **App Manager** · Key ID · Issuer ID · .p8 |

## 3. GitHub Secrets 에 넣기 (레포 Settings → Secrets and variables → Actions → New repository secret)

| 이름 | 값 |
|---|---|
| `APPLE_TEAM_ID` | 팀 ID 10자 |
| `APPLE_CERT_P12` | 배포 인증서 .p12 를 base64 한 문자열 |
| `APPLE_CERT_PASSWORD` | .p12 비밀번호 |
| `APPLE_PROFILE` | .mobileprovision 을 base64 한 문자열 |
| `APPLE_API_KEY_P8` | App Store Connect API .p8 을 base64 한 문자열 |
| `APPLE_API_KEY_ID` | 그 키의 Key ID |
| `APPLE_API_ISSUER_ID` | Issuer ID |

base64 만들기 (윈도우 PowerShell, 결과가 클립보드에 복사됨):
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\경로\파일")) | Set-Clipboard
```

## 4. Supabase 시크릿 (푸시 발송용) — 내가 넣는다. APNs .p8 · Key ID · 팀 ID 만 주시면 됨

```
supabase secrets set APNS_KEY_P8="$(cat AuthKey_XXXX.p8)" APNS_KEY_ID=XXXXXXXXXX APNS_TEAM_ID=YYYYYYYYYY APNS_BUNDLE_ID=com.wontsbe.momcalendar
```

## 7. 올리는 순서 (계정·시크릿이 다 들어간 뒤)

1. GitHub → Actions → **iOS 앱 빌드** → Run workflow → mode `unsigned` → 초록불 확인 (약 10분)
2. 같은 곳 → mode `release` · version `1.0.0` → 끝나면 App Store Connect → TestFlight 에 빌드가 뜬다 (처리 10~30분)
3. TestFlight 앱으로 사장님 아이폰에 설치 → **카카오 로그인 · 찜 · 알림 받기 · 알림 눌러 열기** 확인
   - 알림 테스트: `send-open-push-ios?dry=1` 로 대상 확인 → 실제 발송은 평소 크론(아침 9시)
4. 괜찮으면 App Store Connect 에서 그 빌드를 1.0.0 버전에 붙이고 **심사 제출**  (보통 1~2일)
5. 승인되면 "수동 출시" 눌러 공개. 그 뒤 사이트에 스토어 링크 배너(사장님 승인 후 test → index).
