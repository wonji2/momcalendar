# ORDER_STAFF_CARDNEWS — 맘캘린더 스탭 사이트 '오늘의 인스타 카드뉴스' 다운로드 섹션 추가

## 목적
길아 님이 `@momcal_official` 인스타그램에 음악(노래)을 넣어 직접 업로드할 수 있도록, 기존 스탭 페이지(`staff.html` → `reelcard.html` 탭)에서 **매일 생성된 카드뉴스 이미지 세트(`1080×1440px`, 인스타 3:4 세로 안 잘리는 규격)와 복사용 캡션을 함께 미리보고 다운로드/복사**할 수 있게 추가한다.

## 주의사항 (필수)
- 라이브 `staff.html`을 바로 수정하지 말고, **먼저 `staff_test.html`(또는 `reelcard_test.html`)에서 구현·실측 검증한 뒤** 길아 님/자비스 확인 후 라이브 반영한다.
- 기존 `daily/today.png`, `daily/hotdeal.png`, `daily/sale.png` 다운로드 기능은 그대로 유지한다.

## 데이터 경로 및 규격
- 저장소 내 경로: `daily/cardnews/YYYY-MM-DD/` (예: `daily/cardnews/2026-11-16/`)
- 폴더 구성:
  - `manifest.json`
    ```json
    {
      "date": "2026-11-16",
      "title": "2027년 출산 예정이면 나라에서 총 얼마 받을까?",
      "cta_type": "댓글 DM ('지원금')",
      "slides": [
        "card_1_cover.png",
        "card_2.png",
        "card_3.png",
        "card_4.png",
        "card_5.png",
        "card_6.png",
        "card_7_ending.png"
      ],
      "caption": "[ 공유/저장 필수 ] ...",
      "hashtags": "#맘캘정보 #육아정보 #출산지원금 #2027육아혜택 #아동수당"
    }
    ```
  - 각 이미지: `1080×1440px` (3:4 비율, 인스타 피드·캐러셀 업로드 시 사방 잘림 없음)
- 오늘 날짜 폴더가 없으면 가장 최근 날짜(`daily/cardnews/latest.json` 또는 fallback)를 표시하거나 "오늘 카드뉴스 준비 중" 안내를 띄운다.

## UI 요구사항 (`staff_test.html` / `reelcard` 탭)
1. 상단 또는 `📸 인스타 카드` 탭 안에 **「📰 오늘의 카드뉴스 (3:4 인스타용)」** 섹션 추가:
   - 제목, 날짜, 권장 CTA 배지(저장 / 맞춤 공유 / 댓글 DM) 표시
   - 슬라이드 썸네일 가로 스크롤 또는 3열 미리보기 (`aspect-ratio: 3/4` 유지, 클릭 시 확대)
2. 원클릭 다운로드 & 복사 버튼:
   - **「전체 이미지 다운로드 (N장)」** 버튼: 모바일/PC 브라우저에서 슬라이드 PNG 파일들을 순차 다운로드 (파일명 예: `momcal_2026-11-16_01.png` ~ `07.png`) + 개별 이미지 아래에도 작은 다운로드 버튼 배치
   - **「캡션+해시태그 복사」** 버튼: 클립보드 복사 후 토스트("복사됐어요!") 표시
3. 모바일(갤럭시 Z 플립7 등 세로 화면)에서 버튼이 겹치거나 가로 스크롤이 깨지지 않게 반응형으로 작성한다.
