# 맘캘린더 운영 및 마케팅 분석 데이터 (Analytics)

이 폴더는 수파베이스 DB에서 추출한 맘캘린더의 핵심 운영/마케팅 통계 데이터입니다.
클로드 코드(Claude Code) 작업 시 아래 파일들을 참조하여 인기 공구 랭킹, 검색 트렌드, 마케팅 유입 분석을 수행할 수 있습니다.

## 파일 구성
1. : 전체 공구 중 소비자 터치/클릭 수 Top 500 랭킹 (상품명, 셀러명, 카테고리, 누적클릭수)
2. : 일별/유입경로별(네이버 블로그, 인스타그램, 카페, 검색 등) 방문자 수 통계
3. : 맘캘린더 검색창에서 사용자들이 가장 많이 검색한 브랜드/키워드 Top 200
