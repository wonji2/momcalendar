# 지메일 → 제보함 자동 연결 (구글 앱스 스크립트)

구글 서버에서 10분마다 돈다. PC 가 꺼져도 멈추지 않고 클로드·토큰을 쓰지 않는다.
cs@·app@momcalendar.com 으로 온 메일 중 **사람이 보낸 건의·오류**와 **앱 스토어 심사·정책 메일**만 제보함에 넣고,
이미 도는 클라우드 처리기(`inquiry-cloud.yml`, 10분)가 이어받는다. 인증 코드·보안 경고·광고는 넣지 않는다.

## 설치 (처음 한 번, 2분 · 사장님 지메일 계정으로)
1. https://script.google.com → 새 프로젝트
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 통째로 붙여 넣는다
3. 위 함수 선택칸에서 **`setup`** 을 고르고 ▶ 실행 → 「권한 검토」 → 사장님 계정 선택 → 허용
   (메일 읽기·라벨 붙이기, 외부 주소 호출 권한. 메일을 읽음 처리하거나 지우지 않는다)
4. 실행 기록에 `지메일 제보함: 넣음 N · 건너뜀 N · 실패 0` 이 뜨면 끝. 이후 10분마다 자동
- 확인: 지메일에 `mc-intake` 라벨이 붙는다 · 관리자 페이지 제보 목록에 `[지메일]` 로 시작하는 글이 생긴다
- 끄기: 앱스 스크립트 왼쪽 시계 아이콘(트리거)에서 `intake` 삭제

## 규칙
- 비밀값 없음(사이트에 이미 공개된 anon 키). 코드에 비밀을 넣지 않는다.
- 판정을 바꾸려면 `NOISE_*` / `STORE_*` 정규식만 고친다.
