## 네이버 로그인 임시 규칙 (2026-11-25 · 프로필 통합 설계 `scratchpad/designs/2026-11-25_네이버_로그인_통합.md` 가 확정되기 전까지)
오늘 사장님이 네이버에 네 번 로그인하셨다(경위는 `scratchpad/handoff-log/security_infra_2026-11-25.md` 1절). 같은 일이 없게:
1. **네이버 로그인 창은 인프라부 도구 한 곳만 띄운다**: `node tools/daily/naver_bc_cookie_sync.mjs --login`(real_chrome 프로필: 스마트스토어센터·브랜드커넥트·오늘의집 공용). 다른 도구·채팅은 창을 직접 띄우지 않고 이 명령(또는 인프라부)에 요청한다.
2. **창은 로그인이 확인될 때까지 닫지 않는다.** 확인 = 브랜드커넥트 목록 주소가 200 + 쿠키 서버 반영 완료 + 쿠키가 디스크에 기록되도록 45초 대기(크롬을 바로 강제 종료하면 「로그인 상태 유지」 쿠키도 사라진다).
3. **「로그인 상태 유지」 체크가 기본**: 안내 문구에 항상 넣는다(체크 안 하면 세션 쿠키라 크롬을 닫을 때 풀린다).
4. **같은 계정은 한 창, 하루에 한 서비스 한 번을 넘겨 요구하지 않는다.** PC 프로필이 로그아웃이어도 **서버 쿠키가 살아 있으면 요구하지 않는다**(서버 함수가 죽는 순간 스스로 카톡).
5. 같은 프로필을 두 도구가 동시에 열지 않는다(real_chrome 파일 잠금, 최대 3분 대기). 스마트스토어 주문 취합이 돌 때는 그 도구가 먼저, 쿠키 점검은 서버 ping 으로 하므로 프로필을 거의 열지 않는다.
