## 옮길 때 반드시 바꿀 것

1. 경로: `scratchpad/Pretendard-*.otf` → `scripts/cardnews/fonts/`, `scratchpad/bg_*.png` → `scripts/cardnews/assets/bg/*.jpg`
2. `DATE = "26.11.16 기준"` 같은 상수를 **원고별 값**으로(전역 상수 금지 — 날짜마다 다르다)
3. 표지 상단에 **브랜드 고정 서브 문구** 추가: `공구 · 핫딜 · 세일 · 육아정보 커뮤니티 맘캘린더` (36px/700, 흰색, 그림자·테두리 없음, `x=80, y=114`, 길면 축소)
3-1. 표지 하단 서브 문구는 **고정 금지** — 각 요일 주제·CTA에 맞는 엄마들 말투 한 줄(예: 화요일 `저장 안 하면 순서 밀려요 · 출생신고하면 바로 ㄱㄱ`)
4. 속지 **밀도 규칙** 추가: 마지막 항목 baseline이 1,170~1,240px에 오도록 행 수·설명 줄 수를 조정하고, 벗어나면 렌더 실패로 처리(`lints.check_density()`)
5. 표지 오른쪽 위 **기준일 뱃지는 삭제**(인스타 `1/N` 과 겹침, 2026-11-16 확정) — `date_pill()` 호출을 표지에서 빼고 상단 우측은 비운다. 기준일은 속지 하단 1줄과 캡션 마지막 줄에만
6. 엔딩 상단 아이콘은 선 그린 달력 대신 **맘캘린더 공식 로고**(`momcal-channel-640.png`, 140px, 라운드 마스크)로 교체(2026-11-16 오후 지시)
