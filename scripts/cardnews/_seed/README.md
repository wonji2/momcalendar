# scripts/cardnews/_seed — 승인된 실물 원본 (참고용, 실행 대상 아님)

이 폴더는 **2026-11-16에 실제로 발행된 카드뉴스 8장을 만든 그 코드**를 그대로 보존한 것입니다.
`orders/ORDER_CARDNEWS_PIPELINE.md`를 구현할 때 이 두 파일을 기준으로 옮겨 적으세요.

| 파일 | 내용 |
|---|---|
| `insta_cards.py` | Pillow 렌더러 원본. 색·폰트·자간·표지(사진형/타이포형)·속지(kv/check/rank/visual_grid)·고정 엔딩·`build()` 전부 들어 있음. 표지 배경 그라데이션, 기준일 뱃지, 자간 -2% 처리 방식이 여기 있다. |
| `render_insta_week1.py` | 11/16(월)~11/22(일) 7편의 **원고·캡션 실물**. `episodes/y2026m11.json`으로 옮길 때 이 문장을 그대로 쓴다(길아 님 톤 승인분). |

## 옮길 때 반드시 바꿀 것

1. 경로: `scratchpad/Pretendard-*.otf` → `scripts/cardnews/fonts/`, `scratchpad/bg_*.png` → `scripts/cardnews/assets/bg/*.jpg`
2. `DATE = "26.11.16 기준"` 같은 상수를 **원고별 값**으로(전역 상수 금지 — 날짜마다 다르다)
3. 표지 상단에 **브랜드 고정 서브 문구** 추가: `공구 · 핫딜 · 세일 · 육아정보 커뮤니티 맘캘린더` (26px/700, 흰색, 그림자·테두리 없음, `x=80, y=104`)
4. 속지 **밀도 규칙** 추가: 마지막 항목 baseline이 1,170~1,240px에 오도록 행 수·설명 줄 수를 조정하고, 벗어나면 렌더 실패로 처리(`lints.check_density()`)
5. 표지 오른쪽 위 기준일 뱃지는 그날 날짜로, 엔딩은 전 편 공통 그대로
