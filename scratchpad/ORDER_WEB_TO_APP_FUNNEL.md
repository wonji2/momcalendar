## 3. 작업 코드 지침

### ① 스마트 바텀시트 함수 보강
```javascript
// 📱 상황별 앱 유도 스마트 바텀시트
function promptAppDownload(title, desc) {
  if (typeof _isNativeApp === 'function' && _isNativeApp()) {
    return false; // 앱 환경이면 통과 (정상 기능 수행)
  }
  const el = document.getElementById('appDownloadSheet');
  if (!el) return true;

  if (title) {
    const tEl = el.querySelector('.mc-sheet-title');
    if (tEl) tEl.innerHTML = title;
  }
  if (desc) {
    const dEl = el.querySelector('.mc-sheet-desc');
    if (dEl) dEl.innerHTML = desc;
  }

  el.style.display = 'flex';
  return true; // 웹에서 액션 차단 및 시트 노출 완료
}
```

### ② 각 기능별 핸들러에 인터셉트 적용
1. **공구/핫딜/세일 찜 클릭 (`toggleWish`, `_wishTok` 등)**:
   ```javascript
   if (promptAppDownload('찜한 일정은<br>맘캘린더 앱에서 보관하세요 💜', '앱에 담아두시면 오픈일·마감일 아침에<br>놓치지 않게 딱 알려드려요.')) return;
   ```
2. **오픈 예정 스포 알림 클릭 (`_nxOn`, `_nxOutside` 등)**:
   ```javascript
   if (promptAppDownload('오픈 알림은<br>맘캘린더 앱에서 받아보세요 🔔', '공구 오픈 당일 아침 9시에<br>휴대폰 푸시로 가장 빠르게 알려드려요.')) return;
   ```
3. **내 찜 필터 클릭 (`switchWishFilter` 등)**:
   ```javascript
   if (promptAppDownload('내 찜 목록은<br>앱에서 모아볼 수 있어요 📅', '찜한 공구들을 모아보고 캘린더로 관리하려면<br>맘캘린더 앱을 이용해 주세요.')) return;
   ```
4. **출석체크 클릭 (`openAttendModal` 등)**:
   ```javascript
   if (promptAppDownload('출석 체크는<br>맘캘린더 앱에서 참여하세요 ✨', '매일 출석하고 드리는 특별한 혜택,<br>앱에서 간편하게 챙겨보세요.')) return;
   ```

### ③ 웹 화면 불필요한 로그인 요소 정리
- 상단 우측 알림함(🔔) 숨김 유지 (웹에선 알림 수신 불가).
- 손님 유입 시 뜨는 번거로운 카카오 로그인 권유 팝업(`찜한 공구 안전하게 보관할까요?` 등)은 **웹에서 전면 비활성화**.
- 웹 손님은 가입/로그인 압박 없이 **검색, 공구 캘린더, 핫딜 최저가 링크 클릭을 100% 쾌적하게 사용**하도록 보장.

## 4. 검증 기준
1. 크롬/사파리 웹에서 공구 목록, 핫딜, 세일, 검색창이 로그인 없이 100% 부드럽게 작동하는지 확인.
2. 하트(찜), 오픈 알림, 내 찜 필터, 출석체크 클릭 시 각각 맞춤형 카피의 예쁜 투톤 바텀시트가 뜨는지 확인.
3. 앱(`body.native-app`)에서는 이 바텀시트가 뜨지 않고 본래 찜/알림 기능이 정상 작동하는지 확인.
4. 검증 완료 후 `index.html` 즉시 배포.
