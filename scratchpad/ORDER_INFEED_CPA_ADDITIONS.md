## 1. 사장님 지침에 따른 변경 사항

### ① 태아보험 슬롯 전면 제외
- 보험 사은품 규제(보험업법 특별이익 제공 금지) 및 제휴 심의 페이지 부재로 이번 반영에서 완전 제외.

### ② 가사도우미(미소/청소연구소) 슬롯 1종만 test.html 유지
- **튕김 방지 주의**: `https://momcalendar.com` 같은 앱 내부 주소를 넣으면 안드로이드 앱에서 홈 화면으로 리로드되어 튕김. 임시라도 외부 URL(예: `https://miso.kr` 또는 정식 제휴 발급 URL)로 지정할 것.
- **320px 글자 수 다이어트** (말줄임표 없이 1줄 노출):
  - 제목: `가사도우미 첫 이용 3만 원 할인쿠폰` (17자)
  - 설명: `전문 매니저 가사청소 3만 원 할인` (17자)
  - 배지: `🎁 3만원쿠폰` / 태그: `가사청소` / CTA: `쿠폰받기`
  - 썸네일: 언스플래시 외부 링크 대신 로컬 에셋 저장 및 fallback 처리 (`onerror="this.src='momcal-dousik-thumb.png'"`)

```javascript
{
  id: "miso_cleaning_helper",
  badge: "🎁 3만원쿠폰",
  title: "가사도우미 첫 이용 3만 원 할인쿠폰",
  desc: "전문 매니저 가사청소 3만 원 할인",
  tag: "가사청소",
  cta: "쿠폰받기",
  thumb: "momcal-cleaning-thumb.png", // 로컬 에셋 또는 외부 이미지 시 fallback 필수
  contain: false,
  url: "https://miso.kr" // 정식 제휴 링크 발급 전 임시 외부 링크(앱 홈 튕김 방지)
}
```

### ③ 공정위 준수 `AD` 작은 표기 추가 (필수)
- 인피드 혜택 카드 우측 상단(또는 태그 옆)에 작고 은은한 `AD` 뱃지 표기 추가.
- 스타일 가이드: 폰트 9~10px, 연한 회색(`#999999`), 테두리 연한 회색, 패딩 1px 3px. 콘텐츠 가독성을 해치지 않으면서 표시광고법 기준 충족.
- 기존 5종 + 가사도우미 1종(총 6종) 전 카드에 공통 적용.

## 2. 검증 체크리스트 (클로드 코드 실행)
1. `test.html` 내 `IN_FEED_PROMOS`가 총 6종(기존 5종 + 가사도우미 1종, 태아보험 제외)으로 깔끔히 정돈되었는지 확인.
2. 모든 인피드 카드 우측 상단에 `AD` 뱃지가 은은하게 표시되는지 확인.
3. 320px 초소형 모바일 화면에서 제목과 설명이 말줄임표(...) 없이 완벽히 1줄로 떨어지는지 실측.
4. 카드 클릭 시 앱 홈으로 리로드 튕김 없이 정상 외부 링크로 연결되는지 확인.
5. 검증 완료 후 `test.html` 커밋/배포 및 사장님께 테스트 링크 보고.
