## 📱 [과업 1] 인앱 바텀시트 맘캘봇 UI 규격

### 1. 트리거 (우측 하단 FAB)
- 우측 하단 플로팅 메뉴의 `💬 맘캘봇` 버튼(`.mcb-item`) 클릭 시:
  - 기존: `href="https://pf.kakao.com/..."` (외부 이탈) ➔ **즉시 제거**
  - 신규: `onclick="openMomcalBot()"` 호출하여 인앱 시트 오픈.

### 2. 바텀시트 레이아웃 (`#mcbSheet`)
- **헤더**:
  - 좌측: `💜 맘캘봇` (보라색 포인트 + 15px 볼드 타이포)
  - 우측: `[✕]` 닫기 버튼
- **대화 스크롤 영역 (`#mcbMessages`)**:
  - 최대 높이: 380px (모바일 키패드 올라와도 안 가려지게)
  - 첫 웰컴 말풍선:
    ```text
    반가워요 맘캘러님! 💜
    찾으시는 공구·핫딜을 편하게 물어보시거나,
    "기저귀 핫딜 뜨면 알려줘"처럼 알림을 등록해 보세요!
    ```
  - **4대 퀵 액션 칩 (가로 스크롤)**:
    - `[🔥 오늘 핫한 공구]` ➔ 오늘 오픈/마감 인기 공구 3건 카드 출력
    - `[🛒 최저가 핫딜]` ➔ 최신 핫딜 3건 카드 출력
    - `[🔔 내 키워드 알림]` ➔ 방금 구현된 알림함 시트(`openNotiCenterSheet()`) 바로 열기
    - `[💬 건의·문의하기]` ➔ contact.html 링크 안내
- **하단 입력창**:
  - 좌측: `<input type="text" id="mcbInput" placeholder="예: 압타밀 핫딜 뜨면 알려줘" />`
  - 우측: `[전송]` 보라색 버튼 (#7C54C4)

## ⚡ [과업 2] 자연어 응답 & 키워드 알림 자동 연동 로직

### 1. 키워드 알림 자동 등록 감지
- 손님 입력에 `알림`, `알려줘`, `뜨면`, `알람` 단어가 포함된 경우:
  - 단어 정제: 불용어(핫딜, 공구, 세일, 뜨면, 알려줘, 해줘, 등록, 등) 제거 후 핵심 명사 추출 (예: "압타밀 핫딜 뜨면 알려줘" ➔ `압타밀`)
  - 방금 구축된 키워드 알림 스토리지(`mc_kw_alarms`)에 해당 키워드 자동 `PUSH`!
  - 봇 응답 말풍선:
    ```text
    🔔 '{키워드}' 키워드 알림에 등록해 두었어요!
    특가가 뜨면 맘캘린더 상단 종소리로 바로 알려드릴게요.
    ```
  - 하단에 `[🔔 내 알림 목록 보기]` 버튼 제공.

### 2. 상품 검색 대화 연동
- 일반 단어("기저귀", "냄비", "압타밀") 입력 시:
  - 기존 `items`(공구)와 `hotdeals`(핫딜)에서 해당 단어 즉시 필터링
  - 결과가 있으면: 슬림 카드 형태(제목, 가격, 바로가기 링크)로 상위 3건 말풍선에 출력
  - 결과가 없으면:
    ```text
    지금은 '{키워드}' 공구나 핫딜이 없네요 🥺
    핫딜이 뜨면 바로 알려드릴까요?
    ```
    하단에 `['{키워드}' 알림 등록하기 🔔]` 원클릭 단추 노출!
