## 🛠️ 작업 1. 핫딜 키워드 리치 푸시 알림 (사진 + 가격 + 단위가)

### A. 발송 조건
- 수파베이스 `public.hotdeals`에 신규 핫딜이 INSERT될 때, 손님이 등록한 `user_keywords`와 핫딜 제목(`title`)을 매칭.
- 매칭된 사용자에게 웹 푸시 / FCM 푸시 발송.

### B. 푸시 메시지 페이로드 규격 (BigPictureStyle 리치 알림)
```json
{
  "title": "🔥 [{키워드}] 핫딜 발견! {가격} (▼{할인율}%)",
  "body": "[{쇼핑몰}] {상품명}\n{단위가격}",
  "icon": "/img/momcal-logo-192.png",
  "image": "{h.img_url}",
  "data": {
    "url": "https://momcalendar.com/?ct=hotdeal&deal_id={h.id}",
    "type": "hotdeal_keyword",
    "deal_id": "{h.id}"
  }
}
```
- **실제 알림 예시**:
  - 제목: `🔥 [기저귀] 핫딜 발견! 118,810원 (▼34%)`
  - 내용: `[지마켓] 하기스 맥스드라이 기저귀 3박스 세트 특가 (1장당 349원)`
  - 이미지: 하기스 상품 썸네일 사진 큼직하게 노출
  - 터치 시: 맘캘린더 핫딜 탭으로 진입하며 해당 핫딜 바텀시트(`openHdSheet(id)`) 즉시 오픈.

## 🛠️ 작업 2. 공구 알림 전면 개편 (마감 알림 영구 삭제 & 오픈 당일 1회 발송)

### A. 마감 알림(D-Day 마감 임박) 영구 삭제
- **문제점**: 공구 마감일에 오는 알림은 손님에게 피로감을 주고 스팸으로 인식됨.
- **조치**: 푸시 발송 크론/트리거 코드에서 **공구 마감(종료) 알림 로직을 100% 완전 삭제**한다.

### B. 오픈일 당일 단 1회 발송
- 찜한 공구 또는 키워드 매칭 공구는 **오픈 당일 아침 09:30 (또는 실제 오픈 시각)에 딱 1회만 발송**한다.
```json
{
  "title": "📅 [{셀러명}] 공구 오픈!",
  "body": "{공구명} 지금 오픈되었어요. 프로필 링크에서 확인하세요!",
  "icon": "/img/momcal-logo-192.png",
  "image": "{gonggu.img_url}",
  "data": {
    "url": "https://momcalendar.com/?ct=gonggu&id={gonggu.id}"
  }
}
```

### C. 야간/새벽 발송 원천 차단 (야간 방해금지)
- **문제점**: 새벽 1시, 3시에 라방/공구 푸시가 발송되는 치명적 버그 확인됨.
- **조치**: 발송 시간 검증 로직 추가 (한국 시간 기준 09:00 ~ 21:00 사이에만 발송, 야간 발송 절대 금지):
```javascript
const kstHour = (new Date().getUTCHours() + 9) % 24;
if (kstHour < 9 || kstHour >= 21) {
  console.log('[PUSH SKIP] 야간 방해금지 시간대 (21:00 ~ 09:00) 발송 보류');
  return;
}
```

## 🛠️ 작업 3. 맘캘봇 공구 부재 시 실시간 최저가 핫딜 전환 안내

### A. 챗봇 응답 로직 업데이트 (`bot.js` 또는 `index.html` 맘캘봇 렌더러)
1. **진행 중 공구 있을 때**: 공구 카드 우선 안내 + 하단에 `🔥 실시간 최저가 핫딜도 함께 확인해보세요!` 덧붙임.

   온라인 실시간 역대 최저가 핫딜이 떠 있어요! 득템 찬스 놓치지 마세요 👇
   ```
   ➔ 2열 핫딜 카드(단위가격, 할인율) 바로 노출하여 쿠팡/지마켓 제휴 수익링크로 직결.
3. **공구 예정일 때**:

   지금 당장 급하시다면 현재 진행 중인 최저가 핫딜을 먼저 확인해보세요 👇
   ```

## 🛠️ 작업 4. 수파베이스 6개월(180일) 가격 데이터 자동 보관 & 일별 청소 쿼리

### A. DB 보관 기준
- 차트 기간 탭(`[1개월] [2개월] [3개월] [6개월]`)에 맞춰 **최대 180일까지 보관**.
- 180일 치를 보관해도 핫딜 1,000개 기준 약 20MB(무료 500MB의 4%)로 용량 여유 96% 보장.

### B. 매일 자정 자동 정리 쿼리
GitHub Actions 정기 크론 또는 Supabase Edge Function에 아래 1줄 쿼리 등록:
```sql
DELETE FROM public.hotdeal_history 
WHERE recorded_at < NOW() - INTERVAL '180 days';
```
