## 📱 UI/UX 세부 규격

### 1. 첫 실행 온보딩 래퍼 (`#appOnboardingWrap`)
- 표시 대상: **오직 앱(`_isNativeApp() === true`)**에서 로그인 안 된 상태거나 처음 깐 기기.
  - 단, 검증 및 사장님 확인을 위해 `?onb=1` 파라미터가 있으면 기기 저장 여부 상관없이 무조건 노출.
- 배경: 깨끗한 화이트 (`#FFFFFF`)

### 2. 상단 ➔ 중앙: 실제 앱 구동 영상 슬라이더
- 에셋 위치: `intro/v0.mp4` ~ `intro/v5.mp4` (포스터 `intro/v0.jpg` ~ `intro/v5.jpg`)
- 프레임: 깔끔한 모바일 목업 프레임 안에서 영상이 부드럽게 자동 전환 (기존 10-25 슬라이더 로직 복원)
- 슬라이드 인디케이터 (Dot): 하단에 라일락 보라 포인트 인디케이터.
- 영상 위/아래 헤드 카피:
  ```text
  엄마들의 똑똑한 소비 습관, 맘캘린더
  육아 물가를 절감해줘요 💜
  ```

### 3. 하단: 피클 스타일 52px 알약 로그인 버튼 그룹
- **1순위. 카카오로 시작하기**:
  - `height: 52px; border-radius: 26px; background: #FEE500; color: #191919; font-size: 15px; font-weight: 800;`
  - 좌측에 카카오 심볼 + `카카오로 시작하기`
  - 클릭 시 네이티브 카카오 로그인 트리거
- **2순위. 네이버로 시작하기 (안드로이드/웹)**:
  - `height: 52px; border-radius: 26px; background: #03C75A; color: #FFFFFF; font-size: 15px; font-weight: 800; margin-top: 10px;`
  - 좌측에 N 심볼 + `네이버로 시작하기`
  - 클릭 시 네이버 로그인 트리거
- **3순위. 로그인 없이 둘러보기**:
  - `color: #8B95A1; font-size: 13.5px; font-weight: 600; text-decoration: underline; margin-top: 10px; background: none; border: none;`
  - 클릭 시 온보딩 종료(`mc_onb_done_app` 저장) 및 홈 화면 진입
