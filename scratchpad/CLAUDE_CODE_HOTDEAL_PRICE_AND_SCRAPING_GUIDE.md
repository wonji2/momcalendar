# [클로드 코드 필독] 핫딜 가격 수집 원리와 크롤링 방어 아키텍처 가이드

이 문서는 맘캘린더 핫딜 시스템 운영진(방장 매니저, 원길아 사장님, 두 비서)이 실측 검증하고 사장님 측과 교차 검증을 마친 기술적 진실과 운영 원칙을 정리한 마스터 가이드입니다.

---

## 1. 핫딜 가격 수집의 진실: "쇼핑몰 크롤링 vs 커뮤니티 제목 파싱"

### 1.1 쇼핑몰(지마켓, SSG, 11번가, 롯데온 등) 웹 크롤링이 불가능한 이유
- **대기업 WAF 봇 차단**: Akamai, Cloudflare, 자체 Anti-Bot 솔루션으로 인해 자동화 스크립트 접근 시 HTTP 403, 캡차, IP 차단 발생.
- **쿠폰 및 옵션의 복합성**: 상품 페이지에 접속해도 '대표 시작가'만 노출되며, 실제 핫딜가는 **[선택 옵션 + 빅스마일데이 쿠폰 15% + 카드사 7% 중복할인 + 배송비 결합]**된 최종 체감가입니다. 웹페이지 DOM 파싱만으로는 절대 이 최종 핫딜가를 계산해낼 수 없습니다.

### 1.2 베이비핫딜(bbhd)과 지름알림(jirum)의 실제 가격 수집 방식 (100% 실측)
- **베이비핫딜도 쇼핑몰 상세 페이지를 크롤링하지 않습니다.**
- **커뮤니티 집단지성 활용**: 뽐뿌, 맘이베베, 딜바다, 어미새 등 핫딜 커뮤니티의 알뜰한 유저들이 직접 쿠폰과 카드 할인을 먹여보고 계산한 최종 가격을 글 제목에 적습니다.
  - 예시: `[지마켓] 해피콜 IH 플렉스팬 22cm (15,070원/무료)`
  - 예시: `ssg)플레이모빌 산타 XXL 체감가 101,160원`
- **정규식 제목 파싱 (업계 표준)**:
  ```python
  price_m = re.search(r'([0-9,]+)\s*원', raw_title)
  price = int(price_m.group(1).replace(',', '')) if price_m else 0
  ```
  커뮤니티 제보 글 제목에 사람이 적어둔 정직한 숫자(`15,070원`)를 그대로 정규식 추출하여 DB에 넣는 것이 업계 표준이자 가장 정확한 핫딜가입니다.
- **결론**: 쇼핑몰 상품 페이지에서 가격과 옵션을 직접 긁으려고 하지 말고, 커뮤니티 제보 글 제목에 적힌 가격 숫자를 그대로 파싱하십시오.

## 2. 쿠팡 핫딜 링크 "첫 화면 튕김" 원인과 수습

### 2.1 원인
- 과거 수집기에서 `...page={quote(clean_url)}` 형태로 URL 파라미터를 임의 조립하는 간이 변환(꼼수 조립)을 사용함.
- 쿠팡 보안 정책상 비공식 조립 링크는 상품 상세 페이지를 열어주지 않고 무조건 쿠팡 첫 화면(메인 홈)으로 강제 리다이렉트시킴.

### 2.2 해결 (커밋 `ea8cfac1` 반영 완료)
- 간이 변환을 전면 폐기하고, Supabase Edge Function의 정식 쿠팡 파트너스 API(`functions/v1/coupang-hotdeal?deeplink=`)를 호출해 정식 단축링크(`link.coupang.com/a/...`)를 발급받아 적재.
- API 호출 제한(하루 40회, 회차당 10건, 간격 2.1초) 준수. 변환 실패 또는 상품번호 미추출 시에는 등록하지 않고 건너뜀.

## 3. 핫딜 무단 크롤링 방어 기획 최종 결론 (살릴 것 vs 버릴 것)

두 비서와 원길아 사장님 간 교차 검증을 통해 확정된 3대 절대 원칙:

### 3.1 ❌ 전면 배제 (치명적 부작용으로 절대 구현 금지)
1. **5분 단기 만료 토큰 금지**: 유저가 카톡 '나에게 보내기'로 보관하거나 고민 후 10분 뒤 결제하려 할 때 링크가 깨져 구매 전환율이 폭락함.
2. **쿠팡 홈 강제 튕김 및 Referer 변조 금지**: 쿠팡 파트너스가 비정상 트래픽(어뷰징)으로 간주하여 **계정 영구 정지 및 수익금 전액 몰수** 위험 직면.
3. **JS 터치 이벤트 은닉 및 a href 제거 금지**: 카카오톡 단톡방이나 네이버 카페에 링크 공유 시 `kakaotalk-scrap` 봇까지 튕겨 썸네일 미리보기가 회색 액박으로 깨지고 검색엔진(SEO) 색인에서 탈락함.

### 3.2 ⭕ 유지 및 권장 방어선 (정석 방어)
1. **단축 프록시 원본 은닉 (`r.momcalendar.com`)**: 프론트엔드에 쿠팡/11번가 원본 링크를 직접 노출하지 않고 우리 단축 주소(`r.momcalendar.com/hd/{id}`)로만 서빙 (이미 구현됨).
2. **자연 방어 (역관광 구조)**: 경쟁사 봇이 우리 단축 링크를 긁어가서 자기네 채널에 뿌려도, 그쪽 유저들이 결제하면 수수료는 전부 맘캘린더 제휴 계정으로 입금됨.
3. **Cloudflare WAF 레벨 방어**: 대량 스크래핑 봇 차단은 애플리케이션 코드가 아닌 Cloudflare 대시보드의 무료 'Bot Fight Mode' 및 Rate Limiting으로 인프라 레벨에서 안전하게 처리.
