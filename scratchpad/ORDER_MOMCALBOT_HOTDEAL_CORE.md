# 🤖 [맘캘봇 핫딜 엔진 헌법] 자비스의 핫딜 소싱 및 검증 4대 원칙

## 1. 개요
- **목적**: 맘캘봇이 외부 커뮤니티 및 쇼핑몰에서 핫딜을 긁어올 때, 엉뚱하거나 가짜 할인 상품을 배제하고 **길아 님의 실질 수익(CPS)과 사용자 신뢰**를 동시에 극대화하기 위한 절대 운영 기준.

---

## 2. 핫딜 선별 4대 핵심 기준

### ① 가짜 할인율 차단 & 실질 최저가 판정 (Fake 특가 컷)
- **원칙**: 판매자가 정가를 10만 원으로 부풀려 "80% 세일! 2만 원!"이라고 올리는 가짜 할인은 전면 차단한다.
- **판정 로직**:
  1. **평균가 대비 실질 하락**: 최근 30~90일 추적 평균가 대비 **최소 15% 이상 하락**했는가?
  2. **역대 최저가 (`is_lowest`)**: 수집된 가격 히스토리 중 가장 낮은 가격을 갱신했는가?
  3. **단위 가격(Unit Price) 역산**:
     - 기저귀: 1장당 350원 이하 (프리미엄 450원 이하)
     - 물티슈: 1장당 15원 이하 (100매 기준 1,200~1,500원선)
     - 분유: 800g 1캔당 3만 원 이하
     - 아기 간식/파우치: 개당 1,200원 이하
     - 단위 가격이 평소 시세보다 비싸면 할인율이 높아도 즉시 탈락.

### ② 100% 수익링크(CPS) 파이프라인 직결
- **원칙**: 수수료가 1원도 안 나오는 플랫폼은 시간과 트래픽 낭비이므로 수집하지 않는다.
- **플랫폼 선별**:
  - ❌ **카카오 톡딜**: 외부 공개 어필리에이트가 없어 수수료 0원 ➔ 수집 배제.
  - ⭕ **쿠팡**: 쿠팡 파트너스 API (`AF9014060`)로 100% 실시간 수익링크 변환 (수수료 3%).
  - ⭕ **11번가 / 지마켓 / 옥션 / 오늘의집**: 링크프라이스 (`A100706561`) 머천트 딥링크로 자동 변환.
- **고마진 가전 믹스**:
  - 생필품(물티슈 수수료 300원)만 올리지 말고, **로봇청소기, 공기청정기, 식기세척기, 다이슨, 커피머신 등 50~100만 원대 고가 테크**를 30% 비율로 혼합 (1건만 팔려도 건당 1.5만~3만 원 수익 창출).

### ③ 집단지성 검증 필터 (커뮤니티 반응도)
- **원칙**: 봇이나 바이럴 업자가 올린 쓰레기 글에 낚이지 않는다.
- **수집 조건**:
  - 베이비핫딜, 뽐뿌 육아포럼, 펨코 핫딜 등 원본 글에서 **댓글 5개 이상** 또는 **추천수/조회수 급증** 플래그가 붙은 검증된 글만 파싱.
  - "이거 진짜 싼가요?", "별로인 듯" 댓글이 많은 글은 자동 제외, "쟁여둡니다", "역대급이네요" 반응 딜 우선 등록.

### ④ 상품명 자동 정제 (클린 브랜딩)
- **원칙**: 길아 님의 맘캘린더 라이브 DB를 오염시키는 판촉 어그로 수식어는 파싱 즉시 정규식으로 박멸한다.
- **제거 대상**:
  - `[2주간 펼쳐지는]`, `[단독특가]`, `[매트 장수 계산기]`, `[사은품 증정]`, `[체감가 00원]`, `[무배]` 등.
  - 정제 포맷: **`[브랜드] + [핵심 상품명] + [규격/수량]`** (깔끔한 20자 내외).

## 3. 가격 추적 기간 정책
- **기간 표시**: 30일에 국한되지 않고, **`[30일]` / `[90일]` / `[180일]` / `[전체 기간]`**을 지원한다.
- **데이터 영구 누적**: 수파베이스 `price_history` 테이블에 일자별 가격을 계속 누적하여, 1년 전 가격과 비교 분석이 가능하도록 인프라를 유지한다.
