# 🛡️ 맘캘린더(momcalendar.com) 보안 방패 & 무차단 데이터 수집 장기 운영 헌법

## 1. 개요 및 목적 (원지선 사장님 확정 지침)
- **목적**:
  1. 외부 악성 크롤러가 맘캘린더 DB와 핫딜 수익링크를 무단 복제/탈취하지 못하도록 3대 방어막 구축.
  2. 뽐뿌 403 차단 사례처럼 무식한 직스크랩으로 수집기가 영구 정지되는 일이 없도록, 폴센트·베이비핫딜 등 선배 서비스들이 3~5년간 차단 없이 돌리는 원론적인 장기 운영 원칙을 맘캘린더 팀 전원(비서·매니저·개발팀)이 100% 동일하게 체화하여 적용.

---

## 2. 🛡️ 수비: 맘캘린더 3대 보안 방어막

### ① Cloudflare WAF & Bot Fight Mode (1차 방어선)
- Cloudflare 관리자 콘솔에서 `Bot Fight Mode` 활성화.
- 알려진 악성 파이썬/셀레니움/헤드리스 스크래퍼 봇의 비인가 대량 페이지 스크랩을 엣지 단에서 자동 403/JS 챌린지로 튕겨냄.
- 초당 비정상적 과다 요청 IP는 Rate Limiting으로 1분간 자동 격리.

### ② 링크 은닉 & Cloudflare Worker 리다이렉터 (`r.momcalendar.com`) (2차 방어선)
- 메인 화면에 쿠팡 파트너스/링크프라이스 원본 제휴 링크와 파트너 ID를 날것으로 노출하지 않음.
- 모든 외부 연결은 `https://momcalendar.com/r.html?id=xxx` 또는 Cloudflare Worker(`r.momcalendar.com`)를 경유.
- 카카오톡 공유 시 카카오 스크랩 봇에게는 원본 상품 이미지가 포함된 동적 OpenGraph 메타태그를 내려주고, 실제 손님 클릭 시에만 0.1초 만에 사장님 수익링크로 안전하게 리디렉트.

### ③ Supabase RLS (Row Level Security) 격리 (3차 방어선)
- 클라이언트 `anon_key`로는 `SELECT` 권한만 허용.
- `service_role` 마스터 시크릿 키는 클라이언트 코드(`index.html`)에 절대 노출 금지, 오직 서버리스 함수/GitHub Actions Secret 환경변수에만 엄격 격리.
- 회원 데이터(`members`, `push_tokens`, `wishes`)는 타인이 조회할 수 없도록 RLS 엄격 적용.

### ④ 폴센트형 법적 면책 방패 (`terms.html` & `privacy.html`)
- 통신판매중개자 법적 면책 조항: 맘캘린더는 쇼핑몰과 이용자 간의 거래를 중개하는 플랫폼으로서 상품 가격, 재고, 배송, 환불에 관한 최종 책임은 입점 쇼핑몰에 있음을 명시.
- 4대 클라우드/인프라 수탁사(Supabase AWS 서울 리전, Cloudflare, GitHub, LightNode) 투명 고지.

## 3. ⚙️ 공격/수집: 차단율 0% 장기 무인 파이프라인 4대 정석

### ① 원천 사이트 직스크랩 영구 금지 ➔ 미러링/집계 피드(Aggregator) 경유 원칙
- 대형 커뮤니티(뽐뿌, 맘이베베, 어미새, 디시 등)는 클라우드/IDC IP 대역을 철저히 차단하므로 직접 긁으면 수일 내 WAF 403 차단에 직면함.
- 맘캘린더와 베이비핫딜의 핵심 해법:
  - 16대 커뮤니티의 핫딜을 깨끗하게 집계해 주는 **오픈 미러링 피드(`https://jirum-alarm.com`)** 경유.
    - `/themes/household-essentials`: 뽐뿌 생필품 특가
    - `/themes/baby`: 맘이베베 육아 특가
    - `/themes/appliances-furniture`: 고가 가전 특가
  - 베이비핫딜 보조 피드(`https://www.bbhd.kr/bbs/bbs/board.php?bo_table=free`) 경유.

### ② 스마트 델타(증분) 수집 (`last_id` 추적)
- 매번 전체 목록을 긁어오는 무식한 방식 금지.
- DB(`ops_status`)에 직전 수집한 게시글 고유번호(`last_id`)를 기록해 두고, `wr_id > last_id` 조건의 **새로 등록된 10~15개 신규 글만 핀포인트로 가져오는 스마트 델타 수집** 엄수.
- 원천 서버에 부하를 주지 않아 봇 탐지망에 걸리지 않음.

### ③ 정각 크론봇 패턴 배제 및 지터 분산 (Jittering)
- 매시 00분 00초 등 칼같은 정각 스케줄은 기계적 봇으로 자동 판정됨.
- GitHub Actions 스케줄을 17분, 47분 등 비정각으로 분산하고, 요청 간 수 초의 무작위 딜레이(지터)를 두어 자연스러운 사람의 탐색 패턴을 시뮬레이션.

### ④ 가벼운 핀포인트 패치 & 180일 보관 헌법
- 무거운 브라우저 풀렌더링을 지양하고, 필요한 JSON API/OpenGraph 메타태그만 가볍게 요청.
- 맘캘린더 DB는 180일 초과 과거 핫딜을 매일 자동 정리(`DELETE WHERE deal_day < NOW() - 180 days`)하여 초경량 고속 성능 유지.
