# 📱 [UX 대수술] 웹 불필요 기능 완전 제거 & 카드 찜(하트) 단일 앱 유도 퍼널

## 1. 사장님 절대 방침 (2026-11-02)
- **사장님 말씀**: "글고 누를때마다 앱으로 오라하면 그것도 피곤하니까 웹에선 굳이 못쓰는 기능은 빼버려 오른쪽 위 알람표시처럼. 카드 찜은 냄겨두고"
- **핵심 디자인 철학**:
  1. **누를 때마다 팝업 뜨는 피로도 100% 방지**: 어차피 웹에서 작동하지 않는 기능(알림, 출석체크 등)을 화면에 둬서 누를 때마다 "앱 깔아라" 잔소리하는 피곤한 구조를 **원천 차단**.
  2. **못 쓰는 기능은 화면에서 아예 싹 제거 (Clean & Minimal Web)**: 상단 종(🔔)을 뺀 것처럼, 웹에서 지원하지 않는 버튼은 화면에서 아예 안 보이게 숨김.
  3. **유일한 앱 유도 트리거 = 「카드 찜(하트 💜)」**: 손님이 공구 상품을 탐색하다가 진짜 사고 싶어서 **카드의 하트(♡)를 누르는 결정적인 순간에만** 방금 완성한 예쁜 투톤 바텀시트로 우아하게 앱 설치를 유도!

---

## 2. 세부 작업 지침 (`test.html`, `index.html`)

### ① 웹에서 아예 숨길/제거할 기능 목록 (CSS & HTML)
일반 웹 환경(`!_isNativeApp()`)에서는 아래 요소들을 원천 숨김(`display: none !important;`):
1. **상단 우측 알림함 버튼 (`#bellBtn`, `.noti-bell` 등)** ➔ 이미 숨김 확인.
2. **출석 체크 플로팅 버튼 및 메뉴 항목 (`#attendFab`, `.menu-attend` 등)** ➔ 웹에서는 완전 숨김.
3. **상단 우측/헤더의 '내 찜·일정' 버튼** ➔ 웹에서는 숨기고, 검색창과 로고를 넓고 시원하게 배치.
4. **사이드 햄버거 메뉴 속 웹 미지원 항목**:
   - `오픈 알림 설정`, `내 폰 캘린더 저장`, `출석 체크` 항목은 웹에서 숨김.
   - 오직 `공구 일정 둘러보기`, `핫딜 특가`, `세일/라방`, `이용 방법`, `제휴 문의` 등 둘러보기 메뉴만 단정하게 유지.

### ② 유일하게 살려두는 앱 전환 통로: 「카드 찜(하트 💜)」
- 공구 카드 / 핫딜 카드 우측의 **하트(♡) 버튼은 그대로 유지**.
- 손님이 하트를 톡 누르면:
  - 둔탁한 로그인 팝업 대신,
  - 상단 띠와 똑같은 **시그니처 투톤(Google Play 보라색 + App Store 연회색)** 바텀시트가 스르륵 올라옴:
    - **"찜한 일정은 맘캘린더 앱에서 모아보세요 💜"**
    - **"오픈일 아침 9시 알림부터 키워드 알림까지, 앱에서 놓치지 않게 챙겨드려요."**
- 닫기 누르면 조용히 닫히고 둘러보기 계속 진행.

### ③ 기존 웹 찜/로그인 보유자 자연스러운 이관
- 웹에 이미 찜이나 로그인이 있던 손님에게만 찜 탭이나 메인 상단에 단정한 1줄 띠 노출:
  `💜 맘캘린더 앱 출시! 앱에서 로그인하시면 지금 찜한 공구가 그대로 이어져요. [앱 다운로드 ›]`

## 3. 검증 체크리스트
1. 일반 웹 브라우저로 접속 시 화면이 군더더기 없이 극도로 심플해졌는지 확인 (종, 출석체크, 복잡한 버튼 싹 정리).
2. 공구 둘러보기, 날짜별 캘린더, 핫딜 최저가 링크 클릭이 아무런 방해 팝업 없이 100% 쾌적하게 되는지 확인.
3. 카드의 **하트(♡)**를 눌렀을 때만 유일하게 예쁜 투톤 바텀시트가 뜨는지 확인.
4. 앱(`body.native-app`)에서는 모든 기능(출석체크, 찜, 알림, 4단 하단바)이 완벽히 정상 작동하는지 확인.
5. 검증 완료 후 `index.html` 즉시 배포.
